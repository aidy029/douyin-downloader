# 抖音采集助手 · Chrome 安装教程

## 1. 解压安装包

将 ZIP 解压到一个固定文件夹。安装完成后，请勿删除或移动该文件夹。

## 2. 安装到 Chrome

1. 打开 Chrome，在地址栏输入 `chrome://extensions`，按回车。
2. 开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择解压后的文件夹：文件夹内应能直接看到 `manifest.json` 和本 README。
5. 出现「抖音采集助手」即表示安装成功。如提示站点访问或通知权限，请允许。

安装后，点击浏览器右上角的拼图图标，将「抖音采集助手」固定到工具栏。

## 3. 设置自动保存

1. 在 Chrome 地址栏输入 `chrome://settings/downloads`。
2. 在「位置」中选择文件保存的根目录，例如 `D:\抖音素材`。
3. 关闭「下载前询问每个文件的保存位置」，避免封面、视频和 meta 分别弹出「另存为」。
4. 打开插件，在「下载目录设置」中填写子目录，点击「保存设置」。子目录可留空。

例如：Chrome 下载位置为 `D:\抖音素材`，插件子目录为「收藏」，文件会保存到：

```text
D:\抖音素材\收藏\douyin-作品ID\
  cover.jpg
  video.mp4
  meta.json
```

图文作品会下载图片而非视频。插件只能填写下载根目录下的相对路径，不能直接填写盘符。重复下载会保留原文件，并给新文件追加编号。

## 4. 开始采集

1. 打开抖音网页版，按需完成登录或验证。
2. 打开一个视频或图文作品，等待内容显示，视频可先播放。
3. 点击插件图标，选择「采集当前页面」。
4. 在素材库中点击一次「下载素材」，自动下载该作品的封面、视频 / 图片及元数据。

整组下载完成后发送系统通知；部分文件失败时会提示未全部完成。关闭插件弹窗不会中止已提交的下载。可在 `chrome://downloads` 查看具体下载状态。

素材库支持搜索、导出 JSON 和删除记录。删除记录不会删除已下载文件。卸载扩展会清除素材库，请先导出备份。

## 5. 常见问题

- **找不到清单文件：** 请选择直接包含 `manifest.json` 的文件夹，不要选择 ZIP 文件或外层目录。
- **需要确认三次另存为：** 在 Chrome 下载设置中关闭「下载前询问每个文件的保存位置」。若仍弹出，请检查迅雷 / IDM 等扩展是否接管下载。
- **采集失败：** 刷新抖音页面，完成登录 / 验证并播放后重试。页面结构和平台限制可能影响采集。
- **下载失败：** 媒体链接可能已过期。打开原作品，重新采集后再下载，并查看 Chrome 下载列表的失败原因。
- **没有通知：** 检查扩展通知权限、Windows 通知和勿扰设置，也可直接查看 Chrome 下载列表。
- **更新插件：** 关闭插件弹窗，将新版文件覆盖原目录，在 `chrome://extensions` 点击「重新加载」，再刷新抖音页面。更新时不必先卸载，以免清空素材库。

## 使用说明

本插件用于你有权访问的内容本地归档，请遵守平台条款与版权要求。评论仅保存页面已显示的前 100 条，不自动翻页。素材库保存在当前 Chrome 扩展的本地存储中，与桌面客户端数据库独立。
